## 1. いま何ができているか

2026年11月に、画面と自動化のしくみを一から作り直しました（v2）。入口は `index.html`、前の版は `v1.html` に残っています。

| できること | 中身 |
|---|---|
| 1週間・全車両を1画面 | 月〜土 × 全車両 × 迎え（橙）・送り（青）。iPad が横向きなら迎えと送りを横ならべ（A）、縦向きなら縦積み（C）に自動で切りかわる。2本指か「＋」で拡大、「全体」で戻る |
| マスタ登録なし | 利用者・車・運転手の名簿は、過去の週の表から読みとる |
| 自動の下書き | まだ無い週をひらくと、先週の表を写す。先週お休みの「いつもの人」を戻す（青わく）、先週だけの人にしるし（点線わく） |
| 利用予定の反映 | 「利用記録兼シフト」から読んだ利用予定に下書きを合わせる。足した人・場所を直した人は緑わく |
| AIに伝える | 声や文字の指示 → 変更を色つきで仮表示 →「これでよい」で確定。「毎週の決まりごと」として覚えさせられる。「AIに表を点検してもらう」ボタンあり |
| 矛盾の指摘 | 同じ人が同じ便に2回、時刻の逆もどり、定員超え、利用予定との食いちがい。上の帯の赤い「⚠ 矛盾」 |
| 定員と枠 | 車ごとに最大の乗車人数。枠の数＝定員で、満席の便には足せない |
| 指で直す | 札を長押ししてひっぱる。押すと利用者名・乗る場所・時刻を、ボタンでえらんで直せる |
| 週の切りかえ | 「今週」「来週」の2つだけ |
| 印刷 | 「⋯ → 印刷」で A4 よこ1枚 |

## 4. まだ確かめられていないこと（大事）

1. **本物の AI**：見本の答えを返させて動作を見ただけ。Anthropic の APIキーを「⋯ → 設定」に入れて、実際の聞きまちがい補正・矛盾の確かめ返し・定員の扱いを試す必要がある。
2. **iPad 実機**：長押しでのひっぱり、2本指の拡大、向きでの A/C 切りかえ、Typeless での入力は、パソコンのブラウザ（iPad 相当の大きさ）でしか見ていない。
3. **Dropbox からの自動読みこみ**：`attendance.yml` と `dropbox-setup.html` は一度も実行できていない（作業環境から Dropbox につなげないため）。データ側の Secrets に `DROPBOX_APP_KEY` と `DROPBOX_REFRESH_TOKEN` を登録し、Actions で手動実行して確かめる。登録前は月曜の実行が失敗として記録される（表には影響なし）。
4. **公開ページへの反映**：作業環境から公開ページを開けないので、毎回「反映されたはず」としか言えていない。

## 5. 残っている作業

- **LINE WORKS 配信を新しい表の形につなぐ**（`tools/publish/` と `publish.yml`）。いまは印刷で代用。
- **ひといき・ふぃっとの取りこみ**：送迎表 Excel と「利用記録兼シフト」を受けとり、`import_excel.py` と `attendance-sources.json` で対応。定員も聞いて入れる。
- **取りこみ直すときは `--seats` を付ける**（例：`--seats "セレナ=7,ハイエース=9"`）。付けないと定員が入らず、前に入れた定員も消える。
- **同じ名字が2回**：ファニーの火曜の迎えに、同じ名字の方が2台に入っている（入力のまちがいとのこと。現場で直してもらう）。
- **利用はするが送迎しない方**：連絡らんに「○○様送迎なし」と書いてある日は警告しない。書いていない日は「表にいません」と出る。
- **「13:00迎え」など時刻入りの送迎メモ**は解釈せず、連絡らんにそのまま出している。
- **前の版の後片づけ**：`v1.html`、`masters.html`、`print.html`、`js/ui/`、`js/core/assign.js` などは残したまま。v2 が定着したら消す。
- **お試しモードの見本の日付**が固定（10/26・11/2・11/9）。日がたつと下書きのもとが無くなる。

## 7. 送迎表 Excel・シフト表の読みかた（要点）

- **送迎表 Excel**：1シート＝1週。2行目に日付、`≪車名≫` の見出しで車が区切られ、月〜土が2列ずつ（お名前・時刻）。時刻が午前なら迎え、午後なら送り。時刻の無い短い文字は運転手、長い文字や「様」を含む文字は連絡。
- **利用記録兼シフト**：月ごとのシート（`202611` など）。「氏　名」の見出し行の下に、利用者が1人2行。上の行に「予」「○」「欠」、下の行に送迎メモ（「○○送り」「○○迎え」「送り無」「休み」など）。日の列は見出し行の数字で決まる。年はシート名から取る（見出しの年セルは古いことがある）。
