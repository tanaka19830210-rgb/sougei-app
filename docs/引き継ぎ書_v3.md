## 1. いま何ができているか

| できること | 中身 |
|---|---|
| 1週間・全車両を1画面 | 月〜土 × 全車両 × 迎え（橙）・送り（青）。iPad が横向きなら迎えと送りを横ならべ、縦向きなら縦積み。2本指か「＋」で拡大、「100％」で戻る |
| マスタ登録なし | 利用者・車・運転手の名簿は、過去の週の表から読みとる |
| 自動の下書き | まだ無い週をひらくと、先週の表を写す。先週お休みの「いつもの人」を戻す（青わく）、先週だけの人にしるし（点線わく） |
| 利用予定の反映 | 「利用記録兼シフト」から読んだ利用予定に下書きを合わせる。足した人・場所を直した人は緑わく。来月のシートがまだ無い日は「分からない日」として、はずさない・知らせない |
| AIに伝える | 文字の指示（音声はキーボードのマイクで）→ 変更を色つきで仮表示 →「これでよい」で確定。「毎週の送迎ルール」として覚えさせられる。「AIに表を点検してもらう」ボタンあり |
| 注意の知らせ | 同じ人が同じ便に2回、時刻の逆もどり、定員超え、利用予定との食いちがい。上の帯の**黄色い「⚠ 注意」**（11/23 に「矛盾」から改名・黄色に） |
| 定員と枠 | 車ごとに最大の乗車人数。枠の数＝定員で、満席の便には足せない |
| 指で直す | 札を長押ししてひっぱる。押すと利用者名・乗る場所・時刻を直せる |
| 乗る場所 | 人を選ぶと、その人のその便（迎え・送り）でいちばん多い場所が入る。家が多い人・はじめての人は「自宅」。別の人を選びなおすと入れかわる（自分で打つか場所のボタンを押したあとは変えない） |
| 時刻 | 1つの選択らんで5分きざみ。**迎えは 7:00〜9:30、送りは 15:30〜17:30**（11/27 田中さんの決定）。幅の外の時刻がすでに入っていれば、それも選べるよう残す |
| 週の切りかえ | 「今週」「来週」の2つだけ |
| 印刷・送る | 「印刷」で A4 よこ1枚。「LW送信」で同じ見た目の画像を LINE WORKS へ送る。注意の黄色いわくは印刷・画像には出さない |
| Google ログイン | 事業所の Google アカウントでログインすると、見られる事業所が決まる（左上の切りかえは出ない） |

## 6. 作業のしかた（守ること）

- **公開側に実名・メール・LINE WORKS の ID・Dropbox のファイル番号を入れない**。`node tools/check.js` が data/ の中を検問する。画面の例文やテストも架空の名字（井上・岡田・小林・山田・森本・川口など）。実名入りの画面写真を公開側に置かない（田中さんに見せるのは可）。
- **たしかめ**：変更したら `node test/run.js`（いま163件）と `node tools/check.js` を必ず通す。
- **本番へ出す流れ**：作業ブランチ → プルリクエスト → まとめる（squash）。田中さんは公開ページで試すので、頼まれた変更はそのつど本番へ出す。見た目を変えたら画面写真を見せる（本物のデータで作ったものでよい）。
- **確かめられていないことは、確かめられていないと正直に書く。**
- **本物のデータで画面を見る**：アプリはこのリポジトリから、`/data/` だけデータ側から出す小さな置き場を作る（`tools/publish/render.js` の `startServer({ appDir, dataDir })` が使える）。`?otameshi=1` で開くと、その置き場の data/ を読む。公開側に本物のデータをコピーしない。
- **GAS の更新**：`gas/gate` で `clasp --auth <funny8985 の鍵> push --force` → `clasp ... update-deployment <デプロイID> -d "…"`。**`create-deployment` は使わない**（URL が変わる）。許可の範囲（appsscript.json の oauthScopes）を足したときは、持ち主がエディタで1回許可するまでデプロイを更新しない。
- **GAS のスクリプト プロパティの罠**：設定画面を古いタブのまま保存すると、ほかの値が消える（11/16 に ACCESS が `{}` になり GOOGLE_CLIENT_ID が消え、だれもログインできなくなった）。さわったら7つ（ACCESS・ANTHROPIC_API_KEY・GITHUB_BRANCH・GITHUB_REPO・GITHUB_TOKEN・GOOGLE_CLIENT_ID・SESSION_SECRET）そろっているか見る。
- **鍵・トークン・パスワードは田中さんが自分で入れる。** 鍵の文字をチャットに貼らない・ログに出さない。
- **言葉づかい**：画面・説明・コミットは、やさしい日本語で、結論から。田中さんは障害福祉事業の経営者（非エンジニア）。確定ボタンは「これでよい」。

## 9. ひといき・ふぃっとを足す手順（案）
