## 1. 今回の範囲から外したもの（やらないと決めたもの）

書類として PDF を残したくなったら、配信のしくみ（`tools/publish/render.js`）に

**「他の人が先に保存しました」と出して止める**しくみだけは入れました。

## 3. 動かしてみて決めたいこと（試験運用の観察ポイント）

引き継ぎ書のとおり、まず**ファニーで4週間**試してから他事業所へ広げる想定です。
そのとき次を見てほしいです。

1. **「いつもの車」の設定が、実際の運用に合っているか。**
   ~~いまは「車椅子の方を先に、あとは同じエリアの人が乗っている車へ」という考えかたです。~~
   **【7/29の記述は古いです】**その後に作り直しました。いまの自動割り当ては
   **利用者マスタの「いつもの車」(`usualVans`) どおりに、空いている席だけを埋めます。**
   曜日ごと・迎え／送りごとに、別の車を指定できます。
   いつもの車が未設定の方は自動では乗らず、プールに残ります。
2. **7分きざみが実態に合っているか。** 合わないなら事業所ごとの設定を変えます。
3. **タイルの大きさ・指でのつかみやすさ。** iPad の実機でしか分かりません。
4. **メモの入れかた。** 車ごとのメモと日ごとのメモ、両方を使うか、どちらかで足りるか。
5. **1週間ぶんを作るのに何分かかるか。** 手作業と比べてどれだけ楽になったか。

## 4. 作りとしての宿題（技術面）

| 項目 | いまの状態 | 次に考えること |
|---|---|---|
| ブラウザでの実機確認 | 計算部分のテストと、書きまちがい探しは自動でできています。**画面の操作は実機で確認していません** | iPad Safari で、ドラッグ・印刷・保存を一度通してみる |
