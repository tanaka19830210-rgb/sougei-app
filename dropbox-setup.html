Dropbox とつなぐ 利用予定を毎週自動で読みこむための、はじめの1回だけの準備
設定へ戻る

これは何をする画面か

送迎表の下書きは、Dropbox にある「利用記録兼シフト」の Excel から、その週に利用する方を読みとって作ります。 毎週月曜の朝に自動で読みにいくために、Dropbox の「読むだけの鍵」を1回だけ作ります。 鍵はこの画面には保存されません。出てきた文字を、GitHub のデータ用リポジトリの Secrets に貼りつけて使います。

1. Dropbox でアプリを作る

  1. Dropbox のアプリ作成ページを、シフト表を見られるアカウントで開きます。
  2. Scoped access → Full Dropbox をえらび、名前を付けて作ります（例：sougei-yotei）。
  3. 「Permissions」タブで account_info.read・files.metadata.read・files.content.read の3つにチェックを入れて Submit を押します。
  4. 「Settings」タブにある App key を、下のらんに貼りつけます。（App secret は使いません）

2. Dropbox で許可する

下のボタンを押すと Dropbox の画面が開きます。「許可」を押すと コード が表示されるので、それをこのらんに貼りつけてください。

3. GitHub に貼りつける

  1. データ用リポジトリ（非公開の sougei-data）を GitHub で開き、Settings → Secrets and variables → Actions → New repository secret を押します。
  2. 名前 DROPBOX_APP_KEY に、上の App key を入れて保存します。
  3. 名前 DROPBOX_REFRESH_TOKEN に、「2」で出てきた長い文字を入れて保存します。
  4. Actions タブ →「利用予定を Dropbox から読みこむ」→ Run workflow を押すと、すぐ1回ためせます。緑のチェックが付けば成功です。

このあとは、毎週月曜の朝 8:30 までに自動で読みこまれます。鍵は「読むだけ」で、Dropbox のファイルを書きかえることはできません。使うのをやめるときは、Dropbox のアプリ作成ページでアプリを消してください。
