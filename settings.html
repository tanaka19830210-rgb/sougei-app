データ用リポジトリ（GitHub）

送迎表のデータを入れておく、GitHub の private（非公開）リポジトリを指定します。 作り方は README に手順があります。

「アカウント名 / リポジトリ名」の形で入れます。GitHubのページのURLの後ろの部分です。

わからなければ main のままにしてください。

GitHub の履歴に残ります。空でもかまいません。

この端末で作る事業所をえらびます。あとから割り当て画面でも変えられます。

トークンのあつかい（大切なお願い）

トークンは「あなたの代わりに GitHub をさわれる鍵」です。次のことを守ってください。
  • 共用のタブレットやパソコンには入れないでください。入れる端末は、送迎表を作る人のものだけにします。
  • 権限は最小にします。Contents だけを Read and write、対象はデータ用リポジトリ1つだけにします。
  • 他の人に見せない・送らない・写真に撮らないでください。画面に出すときは「見る」ボタンを使い、すぐ隠します。
  • 漏れたかもしれないときは、GitHub の画面でそのトークンを Revoke（失効）させて、新しく作り直します。
  • 使い終わった端末では、下の「この端末からトークンを消す」を押してください。
  • 期限（Expiration）を付けておくと、うっかり残っても自動で使えなくなります。

読み書きするファイル

アプリが壊れても、データ用リポジトリのこのファイルを開けば送迎表は残っています。
